# codemap 4.6.4 spot check: classification of sampled disagreements

The sample is the one `bench/score.py` draws (held-out group, seed 20261103, five disagreeing edges per language alternating false negatives and false positives). Each row was examined by hand: the import statement in the source file, what the toolchain resolves it to, what codemap reports for that file (`codemap --json --importers <file>`), and codemap's auto-written `.codemap/config.json`. Classification: **codemap wrong** (the statement really does, or does not, import the target), **truth wrong** (the toolchain model missed something the interpreter or compiler does; such cases were fixed in the generator and the run repeated, see bench/README.md), **scope ambiguity** (both answers are defensible under the edge definition).

The pooled Python precision (0.261) is dominated by one repository and one cause: the namespace-package fan-out on stable-diffusion-webui (19,240 false positives against 864 truth edges). Without that repository the held-out Python precision would be 0.983 (5,959 of 6,060); the number is given here for context only and is not a headline figure, because the pre-registered set is scored as a whole. yt-dlp's remaining disagreements are the `from pkg import name` ambiguity: where `name` is both a submodule and an attribute re-exported by `__init__.py` (`from yt_dlp import YoutubeDL`), the benchmark's documented policy picks the module; codemap picks the package. ## Truth generator changes made after seeing results

The first Python run resolved with only the virtualenv on `sys.path` (plus the repo root for the one repository that could not be installed). Its spot check surfaced two kinds of truth misses: `from tests.conftest import strip_ansi` in test files (the repo root is on `sys.path` under `python -m pytest`) and `from common import ...` in standalone scripts (a script's directory is `sys.path[0]`). The generator now models both; every Python repository was rerun. Before and after, held-out: yt-dlp 3,812 truth / 43 FN / 43 FP became 3,831 / 43 / 24; stable-diffusion-webui 834 / 0 / 19,270 became 864 / 0 / 19,240; spec-kit 2,201 / 258 / 305 became 2,431 / 260 / 77. Tuned: pytest 855 / 34 / 29 became 856 / 34 / 28; werkzeug 384 / 11 / 72 became 400 / 16 / 61. The change was made because the interpreter resolves those statements, not because codemap does; both runs' numbers are shown so the effect is visible.
